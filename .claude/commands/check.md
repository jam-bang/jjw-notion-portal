description: lint·typecheck·build를 실행하고 실패 원인을 분석
allowed-tools: Bash(npm run lint:*), Bash(npm run typecheck:*), Bash(npm run build:*)
---

`npm run lint`, `npm run typecheck`, `npm run build`를 차례로 실행해줘.

- 실패하면 에러 메시지와 관련 코드를 읽고 원인과 수정안을 먼저 설명한다 (바로 수정하지 않음)
- 결과는 "lint ✅/❌ · typecheck ✅/❌ · build ✅/❌" 형태로 요약한다
